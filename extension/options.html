Configuration gérée par le centre. Les éléments marqués « Centre » et les réglages grisés sont imposés.

Activez ou désactivez chaque bouton de la barre. Les réglages de chaque fonction restent conservés quand elle est désactivée.

    Adresse du logiciel médical
    
      
    La barre Mail Mutuelle n'apparaît que sur ces adresses. Collez l'adresse d'une fiche patient (ex. https://app.monlogiciel.fr/patients/123) : l'extension en déduit le site et demande l'autorisation à Chrome. Rechargez ensuite l'onglet du logiciel.
    
      
    
        
        
      
    
      
      

      
      Emplacement de la barre
      
      
      Vide : la barre flotte en bas à droite de l'écran. Sinon, sélecteur CSS de l'élément du dossier patient après lequel l'insérer (clic droit sur l'élément > Inspecter > clic droit sur la ligne surlignée > Copier > Copier le sélecteur).
      
      

      
      CRM (facultatif)
      
      
      Chaque formulaire ajoute un bouton « ＋ … » dans la barre. Il ouvre la page du CRM, clique sur le bouton qui ouvre le formulaire (ex. « Nouveau devis »), puis recopie nom, prénom, date de naissance, N° de sécurité sociale et mutuelle. Rien n'est enregistré automatiquement : la secrétaire complète et valide.

      Lecture de la fiche patient
      
      
      Par défaut, l'extension repère seule les libellés « Nom », « Prénom », « N° INSEE », « Né(e) le », « Mutuelle »… Si un champ est mal lu, indiquez ici le sélecteur CSS exact de la valeur (même méthode que ci-dessus). Laissez vide pour la détection automatique.
      
      
      
    
      

    
    
      
      
      
      Utile si plusieurs comptes Google sont connectés dans Chrome : indiquez l'adresse du compte d'envoi (ou son numéro 0, 1, 2 dans l'ordre de connexion).
      
      
      
    
      

    
    
      
      
      Partager les réglages entre postes
      
      
      Les réglages suivent le compte Chrome de chaque secrétaire. Pour équiper un autre poste ou un autre compte : exportez ici, puis importez le fichier sur l'autre poste.
      
      
      
        
        
      
      
      
      Configuration du centre (console Google)
      
      
      Pour imposer cette configuration sur tous les postes : réglez tout ici (modèles, annuaire, CRM, fonctions, signature), puis exportez. Le fichier se colle dans la console Google : Appareils > Chrome > Applications et extensions > Mail Mutuelle > « Règle pour les extensions ».
